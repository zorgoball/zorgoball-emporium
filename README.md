# Zorgoball's Emporium of Electrical Madness

Private first draft of Joshua Lilly's creative technology portfolio.

## Local preview

Open `index.html` directly in a browser, or serve the folder with any static web server.

## GitHub Pages path

This is intentionally a plain static site so it can be pushed to a GitHub repository and published with GitHub Pages later. No deployment or remote repository is configured yet.

Replace the `avatar-placeholder` with the supplied profile image and add the laser-pup video as a local asset when the final media files are ready.
